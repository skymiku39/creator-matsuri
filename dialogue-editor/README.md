# 攤位台詞流程編輯器

給《創作者的文化祭》攤位對話使用的流程圖編輯器。視覺化編輯開場台詞、選項分支、內容與超連結，並匯出符合範本的 **CSV／Excel**，方便接到 RPG Maker MV／MZ 的語句表或自訂插件。

## 快速開始

```bash
cd dialogue-editor
npm install
npm run dev
```

## 匯出格式

| 欄位 | 說明 |
|------|------|
| 編號 | 如 `01_Msg01`、`01_A_Name`、`01_A_Content01`、`01_A_URL` |
| 說明 | 給編輯者看的標籤 |
| zh_TW | 實際台詞／選項文字／URL |
| 備註 | 氣泡、超連結等演出提示 |

可匯入根目錄範本 `《創作者的文化祭》攤位01台詞 - 範本.xlsx`，或專案 JSON（`存專案 JSON`）。

### 已知限制

- 匯出假設「單線開場 → 一個選單 → 各選項線性分支」
- 未連上主幹的節點、循環連線會被標成錯誤並阻擋匯出
- CSV 匯出含 UTF-8 BOM，方便 Excel 開啟
- 選項最多 A–F（對齊 RPGMV Show Choices）

## 節點對應 RPGMV

| 節點 | 遊戲事件概念 |
|------|----------------|
| 對話 | 顯示文章 |
| 選單 | 顯示選項 |
| 選項 | 單一分支入口 |
| 連結 | 開啟外部 URL（需插件或腳本） |
| 結束 | 返回選單或結束對話 |

## 指令

- `npm run dev` — 開發伺服器
- `npm run test` — 單元測試（匯出／匯入 roundtrip）
- `npm run build` — 正式建置
