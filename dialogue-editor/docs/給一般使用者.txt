攤位台詞流程編輯器（免安裝版）v1.1.0

【網頁版（推薦）】
直接用瀏覽器開啟：
https://skymiku39.github.io/creator-matsuri/
資料存在該瀏覽器；換電腦請匯出 JSON 再匯入。

【桌面版怎麼用】
1. 雙擊「DialogueEditor-*-Portable.exe」開啟
2. 關掉視窗就結束，不需另外關閉伺服器
3. 不需要安裝 Node.js 或任何開發工具
4. 完整操作說明也可在程式內開啟「教學」頁

【人物與說話者】
1. 工具列按「人物」：設定預設說話者、新增／改名／刪除角色
2. 變更會立刻套用；按「完成」或 Esc 關閉（拖曳選取文字不會誤關）
3. 選取對話後，右側「說話者」晶片可切換：
   - 預設：用人物設定／工具列的預設名稱
   - 人物名：引用名單裡的角色
   - 自訂：只改這一句的顯示名稱
4. Ctrl 多選多句後再點晶片，可一次改多句說話者

【本版重點】
- 人物設定與說話者晶片（可多人發言）
- Ctrl+Z／Ctrl+Y／Ctrl+Shift+Z 復原與重做
- 匯出 JSON 可交給 creator-matsuri-tools 反編成純文字與流程圖

【建議】
- 編輯完成後按「匯出 JSON」備份
- 換電腦時用「匯入 JSON」還原
- 需要純文字台詞／流程圖時：把 JSON 拖到
  creator-matsuri-tools/dialogue-json-export/匯出.bat
  （請用完整路徑，或直接拖曳檔案到 bat）

【系統】
- Windows 10／11（64 位元）
