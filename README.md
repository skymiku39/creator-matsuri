# 創作者的文化祭

攤位台詞流程編輯器（RPG Maker MV／MZ 用語句表）。

## 專案結構

```
dialogue-editor/          # Vite + React 流程圖編輯器
《…》攤位01台詞 - 範本.xlsx  # 語句表範本
```

## 開發

```bash
cd dialogue-editor
npm install
npm run dev
```

## 版本

目前版本：`0.1.0`（見 `dialogue-editor/package.json`）

- `npm test` — 單元測試
- `npm run build` — 正式建置（請在確認完成後再執行）
